# Gallery photography

The auto-scrolling gallery on Home reads these four files. Until they are
present, `JmPhotoGallery` renders a designed fallback (category gradient +
icon + caption) rather than a broken image, so the section still reads.

| File | Photo |
|---|---|
| `roads.jpg` | Road construction — rollers laying asphalt |
| `transit.jpg` | Metro line at dusk |
| `civic.jpg` | Lotus Temple |
| `water.jpg` | Water treatment plant, aerial |

Export at 1600×1000 or larger, JPEG quality ~80. They are decorative, so each
carries an explicit caption and is marked as such for screen readers.
